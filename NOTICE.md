# Third-party data

`src/main/resources/com/sweatnation/teleports.tsv` is generated from the transport data in
**Shortest Path** by Skretzo: https://github.com/Skretzo/shortest-path

That data is licensed under the **BSD 2-Clause License**. Its license text and copyright
notice are included in `LICENSE-shortest-path`.

SWEAT NATION does not bundle or depend on Shortest Path's code. If Shortest Path is installed,
SWEAT NATION can ask it to draw a route through RuneLite's plugin messages.
